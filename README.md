Configuración de OpenAI
Este proyecto requiere una clave de API de OpenAI y un ID de organización. 
Por motivos de seguridad, el repositorio no contiene el archivo con esta informacion. 
Para que funcione, abre el archivo config.json en Assets/Config/config.json y rellena los campos "openai_api_key" y "organization_id" con tus datos de OpenAI
