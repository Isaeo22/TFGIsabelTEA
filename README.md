# Configuración del proyecto
Este proyecto requiere una clave de API de OpenAI y un ID de organización. Por motivos de seguridad, el repositorio no contiene el archivo con esta informacion. 
Para que funcione:
1. Genera una clave en tu perfil de OpenAI API
2. Abre el archivo config.json en Assets/Config/config.json
3. Rellena los campos "openai_api_key" y "organization_id" con tus datos de OpenAI
4. Guarga y ejecuta el proyecto
